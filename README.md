# Rixsor — ريكسور

مساعد ذكاء اصطناعي شخصي ثلاثي اللغة (عربي / كوردي سوراني / إنجليزي) بواجهة صوت + نص + Avatar متحرك.

## ليش المايكروفون ما كان يشتغل بالنسخة السابقة؟

النسخة الأولى كانت Artifact داخل محادثة Claude، وClaude.ai يعرض الـArtifacts داخل iframe محمي (sandboxed) لا يسمح بتمرير صلاحية المايكروفون للصفحة الداخلية — هذا قيد أمني من المتصفح نفسه (Permissions Policy)، مو خطأ بالكود. الحل: تشغيل Rixsor كتطبيق حقيقي مستقل (هذا المشروع)، وقتها يطلب المتصفح إذن المايكروفون بشكل طبيعي ويشتغل.

## التشغيل محليًا (خطوتين)

```bash
npm install
cp .env.example .env   # ثم افتح .env وحط مفتاح Anthropic API الخاص فيك
npm start
```

افتح المتصفح على: `http://localhost:3000`

اضغط على زر المايكروفون، وافق على إذن الوصول للمايكروفون عندما يسألك المتصفح — بس هذا يصير.

## ليش هيج بنيته (Backend + Frontend)؟

- **الأمان**: مفتاح الـAPI ما يطلع أبدًا للمتصفح؛ يبقى بالسيرفر ويُقرأ من `.env` (متغير بيئة)، بالضبط متل ما طلبت.
- **المايكروفون**: يحتاج الصفحة تكون "حقيقية" (origin خاص فيها) مو Artifact مضمّن بمحادثة.
- **التوسّع لاحقًا**: `server.js` جاهز لإضافة Tool Manager، قاعدة بيانات، أو مصادقة مستخدمين بدون إعادة بناء الواجهة.

## النشر (Deploy) إذا تريد رابط دائم

انشر نفس المشروع على أي منصة تدعم Node.js (Render, Railway, Fly.io, Vercel Functions...) وضيف متغير البيئة `ANTHROPIC_API_KEY` من إعدادات المنصة — نفس الكود يشتغل بدون تعديل.

## القيود الحالية (بصراحة، مو مخفية)

- التعرف على الصوت (STT) والنطق (TTS) يعتمدان على متصفحك (Web Speech API)؛ دعم الكوردية السورانية بالصوت غير مكتمل بمعظم المتصفحات حاليًا — **Coming Soon**.
- هذا تطبيق Web قابل للتشغيل من أي جهاز عبر المتصفح؛ نسخة مثبّتة (installer) لـ Windows / Android / iOS تحتاج مرحلة تالية (Electron / Capacitor).
- الذاكرة محفوظة محليًا بمتصفحك (localStorage) — تقدر تشوفها/تعطلها/تمسحها من ⚙️ Settings.
